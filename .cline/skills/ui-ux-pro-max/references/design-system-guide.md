# 设计系统指南

供 ui-ux-pro-max 在给出配色、间距、排版与可访问性建议时使用的参考规范。

## 1. 色彩体系

**中性色（最常用，占 60%+）**
| Token | 示例 |
|-------|------|
| 背景 | `#f7f7f8` / 白 `#ffffff` |
| 表面(卡片) | `#ffffff` |
| 主文字 | `#111827` |
| 辅助文字 | `#6b7280` |
| 边框 | `#e5e7eb` |

**主色 / 强调色（占 20–30%）**
- 选一个中明度的品牌色作为主色（Primary）。深色模式需相应提高明度。
- 强调色（Accent）仅用于关键 CTA 与高亮，避免与主色冲突。

**语义色**
- 成功：`#16a34a`、警告：`#d97706`、错误：`#dc2626`、信息：`#2563eb`。
- 语义色要同时提供浅色底 + 深色底的对比方案。

## 2. WCAG 对比度速查

| 用途 | 最小对比度 |
|------|-----------|
| 正文文字 | ≥ 4.5 : 1 |
| 大字号(≥18.66px 粗 或 ≥24px) | ≥ 3 : 1 |
| UI 组件 & 图形 | ≥ 3 : 1 |

**快速判断**：主文字用 `#111827` 配白底（≈17:1），辅助文字 `#6b7280` 配白底（≈4.5:1）达标。浅灰文字（如 `#9ca3af`）作为正文会低于 3:1，只能当禁用态/装饰。

校验命令：
```bash
python scripts/contrast_check.py --fg "#111827" --bg "#ffffff"
```

## 3. 间距 Scale（4px 基准）

`4, 8, 12, 16, 24, 32, 48`
- 组件内 padding：常用 `8/12/16`。
- 组件间间距：常用 `12/16/24`。
- 区块/分区间距：常用 `32/48`。
- 避免使用 3、5、7 等非 Scale 值；需更精细时用 `xxs=x` 注释说明。

## 4. 排版层级

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Display | 32–40 | 700 | 落地页主标题 |
| H1 | 28 | 700 | 页面主标题 |
| H2 | 22 | 600 | 区块标题 |
| H3 | 18 | 600 | 卡片/小组标题 |
| 正文 | 14–16 | 400 | 正文 |
| 辅助/说明 | 13 | 400 | 次要说明 |
| Caption | 12 | 400 | 标签、时间 |

行高：正文 ≥ 1.5，标题 1.2–1.35。中文场景注意中文字面间距默认即可，勿用负字距。

## 5. 圆角与阴影

- 圆角档位：`4 / 8 / 12 / full`。
- 阴影建议两档：
  - 轻：`0 1px 2px rgba(0,0,0,0.06), 0 1px 3px rgba(0,0,0,0.10)`
  - 重：`0 10px 25px rgba(0,0,0,0.12)`
- 阴影仅用于"浮起"的层级（弹窗、下拉、hover），避免全局滥用。

## 6. 导出设计 Token 示例（CSS 变量）

```css
:root {
  --color-bg: #ffffff;
  --color-surface: #ffffff;
  --color-text: #111827;
  --color-text-muted: #6b7280;
  --color-border: #e5e7eb;
  --color-primary: #2563eb;
  --color-success: #16a34a;
  --color-warning: #d97706;
  --color-error: #dc2626;
  --space-1: 4px; --space-2: 8px; --space-3: 12px;
  --space-4: 16px; --space-6: 24px; --space-8: 32px; --space-12: 48px;
  --radius-sm: 4px; --radius-md: 8px; --radius-lg: 12px;
  --font-body: 14px; --font-h2: 22px; --font-h1: 28px;
}
```
