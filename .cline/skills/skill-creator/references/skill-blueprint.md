# SKILL.md 编写蓝图

详细说明如何书写一份高质量、可被 AI 直接调用的 `SKILL.md`。供 skill-creator 在编写新技能时参考。

## 1. Front-matter（YAML 元数据）

必须位于文件的**最顶部**，以 `---` 包裹。两个必需键：

```yaml
---
name: my-skill
description: >
  一句话说明技能干什么。然后列出常见触发说法（中文 + 英文），用逗号隔开，
  如：“生成报告”，“帮我做 XX”，“build a report”，“make a widget”.
---
```

**规则：**
- `name` 必须与技能目录名一致，全小写、连字符分隔。
- `description` 中的触发词越多，AI 越容易在合适时机调用该技能。
- `description` 用 `>` 折行引用符书写，即使跨行也是一整个字符串。

## 2. 正文结构（推荐的节顺序）

```
# 技能名 — 一句话概述

## Quick Start / 前置条件
  依赖安装、环境变量、最小可用步骤。

## 核心工作流
  编号列出执行步骤，命令给全路径与参数示例。

## 脚本参考
  表格列出 scripts/ 下每个脚本：功能 / 是否需 API Key / 输入 / 输出。

## 错误处理
  脚本失败返回什么、边界情况如何处理。

## 进阶模式
  关键词扩展、批量运行、特殊 Flag 等。

## 参考文件
  指向 references/ 下的详细文档。
```

## 3. 写作原则清单

- [ ] 命令可复制运行（含参数示例），不用占位符空壳
- [ ] 输出格式用代码块给出**实际模板**
- [ ] 判断型任务给出**明确定义**的准则/阈值和反例
- [ ] 触发词**中英双语**覆盖
- [ ] 引用外部资料时给出相对路径链接，并确保文件存在
- [ ] 不依赖真实外部 API Key 时，明确标注“无需 Key”

## 4. 最小可用示例

```markdown
---
name: hello
description: 打印问候。 触发：问候，“打招呼”，“say hello”.
---
# Hello — 简单问候技能
运行：`python scripts/hello.py`
```

```python
# scripts/hello.py
print("你好！有什么可以帮你？")
```
